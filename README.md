# Trading Dashboard (`tradingbot-dashboard`)

Real-time monitoring and governance review web application for the IBKR algorithmic trading bot ecosystem, hosted on **Google Cloud Run**.

---

## 📊 Overview

The dashboard provides institutional-grade visibility into active bots, position allocations, real-time market data, telemetry, and autonomous governance decisions:
- **Live Position & P&L Tracking**: Dynamic per-bucket tracking, realized/unrealized profit calculation, and option overlay P&L.
- **Bot Health & Heartbeats**: Continuous connection monitoring with status signals (online/offline, last heartbeat latency).
- **Interactive Technical Charts**: Live 1-minute and 5-minute candlestick charts with SMA 5, SMA 20, and SMA 200 indicators.
- **StockPicker & Market Regime**: Integrated multi-symbol screener displaying market regimes (Bullish, Bearish, Neutral, Volatile).
- **Governance Review View**: Dedicated audit interface displaying:
  - Exit proposals (`ExitDiff`) generated by automated analysis.
  - Closed-loop threshold adjustment ledger (`correction_ledger` / `adaptive_action_log`).
  - Active adaptive agent states and drift safety limits.
- **Bot Control REST API**: Remote controls to pause/resume trading, initiate graceful position exits, or adjust active parameters without SSH.

## 🛠️ Architecture & Tech Stack

```
tradingbot-dashboard/
├── main.py                     # FastAPI application backend, Firestore reader & REST API
├── static/                     # Modern vanilla frontend
│   ├── overview.html          # Multi-bot overview & aggregate metrics
│   ├── nvda_focus.html        # Symbol-focused deep dive (NVDA/IWM)
│   ├── governance_review.html # Governance review & adaptive action ledger
│   ├── stockpicker.html       # Stock screening & regime scanner
│   ├── styles.css             # Dark theme high-performance styles
│   └── js/                    # Modular frontend controllers
├── tests/                     # Test suites (API routes, serialization, and Firestore mocks)
├── Dockerfile                 # Container image specification for Cloud Run
└── requirements.txt           # Python dependencies (FastAPI, uvicorn, google-cloud-firestore)
```

**Technology Highlights:**
- **Backend**: FastAPI (Python 3.10) with asynchronous request handlers.
- **Persistence**: Google Cloud Firestore (collections: `bot_overview`, `trade_history`, `adaptive_action_log`, `governance_proposals`).
- **External Feeds**: Alpha Vantage API (market data fallback), REST API integration with VM `bot_control_api`.
- **Hosting**: Google Cloud Run (fully managed serverless container runtime).

## 🚀 Key API Endpoints

### State & Telemetry
- `GET /api/bot-overview`: Comprehensive multi-bot status, open positions, buckets, and P&L.
- `GET /api/bot-status/{symbol}`: Granular metrics, active SMA values, regime, and heartbeat time.
- `GET /api/historical-bars/{symbol}`: Historical price bars for chart rendering.
- `GET /api/logs?bot={symbol}&level={lvl}&limit={n}`: Filtered real-time log streaming.

### Governance & Adaptive Logs
- `GET /api/governance/proposals`: Pending and applied exit tuning proposals (`ExitDiff`).
- `GET /api/governance/ledger`: Audit history of all parameter nudges made by the adaptive engine.
- `POST /api/governance/action`: Approve, reject, or rollback proposed parameter modifications.

### Bot Commands (Proxied to VM)
- `POST /api/bot-control/{symbol}/pause`: Pause new entries for a given symbol.
- `POST /api/bot-control/{symbol}/resume`: Resume active trade entries.
- `POST /api/bot-control/{symbol}/close-all`: Initiate graceful position liquidations.

## 🧪 Testing & CI/CD Pipeline

The dashboard repository features accelerated GitHub Actions CI/CD workflows:
- **`actions/setup-python@v5` with pip caching**: Dependencies are cached to minimize build and test times.
- **Parallel Testing (`pytest -n auto`)**: Test suite runs in parallel across all runner vCPUs on both PR checks and deployments.
- **Automatic Deployment (`deploy-to-cloudrun.yml`)**:
  - Automatically triggered on push to `main`.
  - Runs tests and builds container image via Google Cloud Build.
  - Deploys updated image to Cloud Run with zero downtime.

## 💻 Local Development

```bash
# 1. Install dependencies
pip install -r requirements.txt
pip install pytest pytest-xdist

# 2. Run unit tests
pytest tests/ -n auto -v

# 3. Export credentials and start server
export GOOGLE_APPLICATION_CREDENTIALS="../tradingbot-secrets/service-account-key.json"
uvicorn main:app --reload --port 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
