# Trading Dashboard (`tradingbot-dashboard`)

Real-time institutional monitoring, governance review, execution performance benchmarking, and bot control web application for the IBKR trading bot ecosystem, hosted on **Google Cloud Run**.

---

## 📊 Overview

The dashboard provides institutional-grade visibility into active bots, position allocations, real-time market telemetry, and autonomous governance decisions:
- **Clean Standardized Header UX**: Unified controls across all tabs with live metadata pills (Environment badge, Market Status, Last Updated timestamp, API Latency) and a custom auto-refresh dropdown.
- **Top-Level Animated Progress Bar & Tile Spinners**: Real-time visual feedback during page loads, data refreshes, and bot switching.
- **Live Position & P&L Tracking**: Dynamic per-bucket tracking, realized/unrealized profit calculation, and option overlay P&L.
- **Interactive Technical Charts**: Live 1-minute and 5-minute candlestick charts with SMA 5, SMA 20, and SMA 200 indicators.
- **Trading Engine Performance Scorecard (`/performance`)**: Quantitative evaluation metrics including Sharpe, Sortino, Calmar, execution latency, fill slippage, markout metrics, SEC Rule 605/606 benchmark comparisons, and Fama-French factor context.
- **Governance Review & Adaptive Ledger (`/governance`)**: Audit interface displaying:
  - Exit proposals (`ExitDiff`) generated by automated analysis.
  - Closed-loop threshold adjustment ledger (`applied_changes` / `adaptive_action_log`).
  - Active adaptive agent states and ±35% drift safety limit monitoring.
- **Learning Review (`/learning-review`)**: Reviewing candidate observations and dict-shaped escalation pairs from the nightly learning engine.
- **StockPicker & Market Regime (`/stockpicker`)**: Multi-symbol screener displaying market regimes (Bullish, Bearish, Neutral, Volatile).
- **Secure Bot Control REST API**: Remote controls to pause/resume trading, initiate graceful position exits, or adjust active parameters without SSH. Authenticated with `X-API-Key` (`BOT_CONTROL_API_KEY`).

**Technology Highlights:**
- **Backend**: FastAPI (Python 3.10+) with asynchronous request handlers.
- **Persistence**: Google Cloud Firestore (collections: `bot_overview`, `trade_history`, `adaptive_action_log`, `governance_proposals`, `learning_candidates`).
- **Authentication**: Bot control actions require matching `BOT_CONTROL_API_KEY` passed in `X-API-Key` headers to the VM daemon.
- **External Feeds**: Alpha Vantage API (market data fallback), REST integration with VM `bot_control_api`.
- **Hosting**: Google Cloud Run (fully managed serverless container runtime).

## 🚀 Key Routes & API Endpoints

### UI Views
- `GET /`: Fleet overview dashboard.
- `GET /bot/{symbol}`: Deep-dive view for a specific bot (e.g. `/bot/NVDA`).
- `GET /governance`: Governance proposals and applied changes ledger.
- `GET /learning-review`: Review nightly learning candidates.
- `GET /performance`: Quantitative execution performance scorecard.
- `GET /stockpicker`: Regime scanner and screener.

### Telemetry & Data APIs
- `GET /api/bot-overview`: Comprehensive multi-bot status, open positions, buckets, and P&L.
- `GET /api/bot-status/{symbol}`: Granular metrics, active SMA values, regime, and heartbeat time.
- `GET /api/historical-bars/{symbol}`: Historical price bars for chart rendering.
- `GET /api/performance/summary`: Aggregate execution metrics, markout, slippage, and Sharpe ratios.
- `GET /api/logs?bot={symbol}&level={lvl}&limit={n}`: Filtered real-time log streaming.

### Governance & Adaptive Logs
- `GET /api/governance/proposals`: Pending and applied exit tuning proposals (`ExitDiff`).
- `GET /api/governance/ledger`: Audit history of all parameter nudges made by the adaptive engine.
- `POST /api/governance/action`: Approve, reject, or rollback proposed parameter modifications.

### Bot Commands (Proxied to VM with `X-API-Key`)
- `POST /api/bot-control/{symbol}/pause`: Pause new entries for a given symbol.
- `POST /api/bot-control/{symbol}/resume`: Resume active trade entries.
- `POST /api/bot-control/{symbol}/close-all`: Initiate graceful position liquidations.

## 🧪 Testing & CI/CD Pipeline

- **Parallel Testing (`pytest -n auto`)**: Test suite runs in parallel across all runner vCPUs on PR checks and deployments.
- **Automatic Deployment (`deploy-to-cloudrun.yml`)**:
  - Automatically triggered on push to `main`.
  - Runs unit tests and builds container image via Google Cloud Build.
  - Deploys updated image to Cloud Run with zero downtime.

## 💻 Local Development

```bash
# 1. Install dependencies
pip install -r requirements.txt
pip install pytest pytest-xdist

# 2. Run unit tests
pytest tests/ -n auto -v

# 3. Export credentials and start server
export GOOGLE_APPLICATION_CREDENTIALS="../tradingbot-secrets/service-account-key.json"
export BOT_CONTROL_API_KEY="your-secret-key"
uvicorn main:app --reload --port 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
